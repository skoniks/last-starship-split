# Last Starship — Контекст для перевода

## Жанр и сеттинг

Космическая стратегия-песочница (sci-fi, XXIII век). Игрок — капитан корабля, который строит, оснащает и управляет им.
Смешение: конструирование корабля, управление ресурсами и автоматизацией, тактический бой в реальном времени, сюжетная кампания.
Человечество колонизировало звёзды; мощные корпорации доминируют в регионах космоса.

## Режимы игры

- **Boldly Go (STARGATE)** — сюжетная кампания. CEO INTERSTELLAR MINING CORPORATION ставит задачу: построить ЗВЕЗДНЫЕ ВРАТА, способные перенести в галактику Андромеда. Игрок — капитан, участвующий в галактическом мегапроекте.
- **Survival** — тёмная аномалия THE COLLAPSE (расширяющаяся пустота) поглощает галактику. Единственная надежда — недостроенные ЗВЕЗДНЫЕ ВРАТА. Игрок должен добраться до Врат с как можно большим числом выживших.
- **Free Roam** — свободная игра без аномалии и Врат.
- **Arena** — флотские сражения (GREEN TEAM vs RED TEAM — команды игроков, не экипаж).
- **Creative** — неограниченные ресурсы для постройки любого корабля.

## Сюжет (Boldly Go)

Кампания делится на эпизоды (PART 1–5). Ключевые персонажи:

- **Commander Harken** — начальник частной охраны сектора, повторяющийся союзник и заказчик миссий. Обращается к игроку на «вы».
- **Captain Amelia Ryker** — персонаж эпизода «Wolf».
- **Artemis** — учёный (исследования кристаллов тиддлетов, управление кораблём Андромеды).
- **Alexander James Elistar** — (покойный) конструктор Звёздных Врат, оставляет игроку «бэкдор».
- **The Andromeda Project / Andromeda HQ / Andromeda Flagship** — антагонистический конгломерат.

Эпизоды:
1. **Call to Arms** — Harken вербует капитана для расследования исчезновения торговых судов (кризис пиратства).
2. **Wolf in Sheep's Clothing** — расследование невидимого пиратского корабля; сбор Бортовых Самописцев и обломков; погоня.
3. **Rise of the Machines** — поиск пропавшего корабля Celestial Hammer; тема пробуждения ИИ; криминалистика.
4. **Brave New Sector** — после запуска Врат: исследование нового сектора, новые ресурсы (Нейбидиум, Зелеон), история древней галактической войны; Elistar устанавливает бэкдор и умирает.
5. **The Final Stand** — финальная битва: Andromeda Project закрыл Врата и бросил колонистов. Игрок загружает вирус, захватывает HQ, сражается с флотом Андромеды и её Флагманом, освобождает новую галактику.

## Ключевые механики (для понимания контекста строк)

- **Энергосеть (Power Grid)** — Реактор генерирует мощность (МВт), Батареи хранят запас (МДж). Игрок распределяет мощность по категориям: ДВИГАТЕЛИ, ОРУЖИЕ, ЗАЩИТА, ГИПЕРПРЫЖОК, ПРОМЫШЛЕННОСТЬ, ЖИЗНЕОБЕСПЕЧЕНИЕ, ЛОГИСТИКА, ДОБЫЧА, НАУКА, ЗВЕЗДНЫЕ ВРАТА.
- **Логистика** — автоматическая система перевозки грузов. Приказы: Купить, Продать, Добыть, Собрать Газ, Перевезти. Дроны и челноки перемещают груз между кораблями.
- **Промышленность** — производственное оборудование с буфером (STOCKPILE), сборочные линии.
- **Дерево технологий** — узлы исследований за Чипы Данных (Research Credits) и Вычислительные Очки (CP). Открывают чертежи: автоматизация, дроны, жизнеобеспечение, оружие, двигатели и т.д.
- **Тактический бой** — реальное время: ОГОНЬ, УДЕРЖИВАТЬ, УВОРАЧИВАНИЕ, МАНЕВР, ТРОССЕЛ, автоприцел, Формация Флота, ИИ боя флота, истребители (ВЫПУСК/УБРАТЬ), стыковка.
- **Звёздные Врата** — мегапроект. Строится по Фазам, требует большой мощности (МВт), компоненты открываются через исследования.
- **Гиперпрыжок (FTL)** — сверхсветовой перелёт между системами: зарядка, перезарядка, выбор цели, прыжок.
- **Экипаж / Жизнеобеспечение** — члены экипажа могут погибнуть от отравления CO2, обезвоживания, голода, удушья, радиации, травмы. Состояния: ОБЕЗВОЖЕН, ПОТЕРЯЛ СОЗНАНИЕ, ОБЛУЧЕН, ОШЛОМЛЕН, УДУШАЕТСЯ, БЕЗ СОЗНАНИЯ, ТРЕБУЕТСЯ СКАФАНДР.

## Повторяющиеся концепции (важно для перевода)

- **ЗВЕЗДНЫЕ ВРАТА (STARGATE)** — центральный мегапроект, всегда как название (заглавные).
- **THE COLLAPSE** — расширяющаяся аномалия (режим Survival).
- **Андромеда / Andromeda Project / Andromeda HQ / Andromeda Flagship** — целевая галактика и антагонистический конгломерат.
- **Бортовой Самописец (Black Box Flight Recorder)** — устройство криминалистических доказательств (собирается дронами).
- **Тиддлеты (Tiddlets)** — защищённое существо, производящее кристаллы.
- **Нейбидиум (Neubidium)** — новый ресурс нового сектора.
- **Зелеон (Zeleon)** — новый газ нового сектора.
- **Crew = Экипаж** (члены экипажа корабля), **Team = Команда** (игроки в арене).
- **Обращение к игроку**: всегда «вы/вас/ваш» (не «ты/тебя/твой»).
- **Единицы**: МВт (мощность), МДж (запас энергии).
